## 📥 ¿Cómo descargar e instalar en Windows?

Para que cualquier usuario pueda instalar y usar OpenBake-POS:

1. Entra a la página de **[Última Versión (Releases)](https://github.com/Chrystofer-Castillo/OpenBake-POS/releases/latest)**.
2. En la parte inferior, dentro de **Assets**, haz clic sobre el archivo instalador:
   - **`OpenBake-POS_2.0.0_x64-setup.exe`** (o similar `.exe`).
3. Ejecuta el archivo descargado y sigue el asistente de instalación.
4. ¡Listo! Tendrás el acceso directo de **OpenBake-POS** en tu escritorio.

## ✨ Características Principales

* 🍨 **Laboratorio de Heladería & Recetas:** Cálculo técnico en tiempo real de POD (Poder Edulcorante), PAC (Poder Anticongelante), balance de grasas y sólidos lácteos para formulación precisa.
* 📦 **Inventario & Control de Costos:** Costeo automático de recetas por gramo/mililitro según compras de materia prima, control de mermas y alertas de stock mínimo.
* 🧾 **Punto de Venta (POS) & Facturación:** Registro ágil de ventas, control de caja, soporte multimoneda (USD / Bs con tasa de cambio) y exportación de recibos/facturas en PDF y Excel.
* 👥 **Clientes & Cobranzas:** Directorio de clientes con saldos pendientes y recordatorios automáticos formateados para WhatsApp.
* 🎨 **Temas Artesanales:** 8 paletas de color inspiradas en heladería (Vainilla Clásica, Fresa & Frambuesa, Chocolate Negro, Menta, Espresso, etc.).
* 🔒 **100% Privado y Offline:** Tus datos se guardan directamente en tu equipo. No requiere conexión a internet para trabajar.

## 🛠️ Tecnologías

* **Frontend:** React 19, TypeScript, Vite, Vanilla CSS modular.
* **Núcleo de Escritorio:** Tauri 2 (Rust nativo de alto rendimiento y bajo consumo de memoria).
* **Almacenamiento:** Base de datos local Offline-First con exportación/importación de copias de seguridad.
